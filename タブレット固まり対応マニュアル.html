👀

まず画面を確認してください

「接続できません」「サイトに到達できません」と表示されている  →  STEP 3 へ（PCのサーバーが止まっています）
画面は出ているがタップしても反応しない・くるくる止まらない  →  STEP 1 から順番に試してください

1
画面を更新する　（これだけで直ることがほとんどです）
タブレットでの操作
  1. 画面を上から下に引っ張って離す（Safari / Chrome 共通）
  2. または、ブラウザ上部の ⟳ 更新ボタン をタップする

※ 少し待ってから予約一覧が表示されれば完了です

✔ 直った　→　そのまま使ってください   ✘ まだ固まっている　→　STEP 2 へ
2
タブを閉じて開き直す・Wi-Fiを確認する
A) タブを閉じて再度開く
  1. ブラウザのタブを完全に閉じる
  2. ブラウザを再度開いて
    アドレス欄に以下を入力
    192.168.0.5:5000
  3. 予約台帳が表示されれば完了
B) Wi-Fi接続を確認する
  1. タブレットの設定を開く
  2. Wi-Fi をタップ
  3. 店のWi-Fiに繋がっているか確認
  4. 繋がっていなければタップして接続し、Aの手順でアクセス
✔ 直った　→　そのまま使ってください   ✘ まだ直らない　→　STEP 3 へ（PCの確認が必要）
3
PCのサーバーを再起動する

💻 レジ横のPCで操作します

  1. デスクトップ（またはタスクバー）の 予約システム起動.bat をダブルクリック
  2. 黒い画面（コマンドプロンプト）が開く
  3. 以下のように表示されたら起動成功
バックアップ完了: backup\reservations_20260530.db
予約システムを起動中...
iPadからは http://192.168.0.5:5000 でアクセスしてください
* Running on http://0.0.0.0:5000
* Press CTRL+C to quit
起動後にタブレットで操作
  1. タブレットのブラウザで 192.168.0.5:5000 を開く
  2. 予約台帳が表示されれば完了
✔ 直った　→　そのまま使ってください   ✘ まだ直らない　→　STEP 4 へ
4
黒い画面がすでに開いているのに動かない場合
PCの黒い画面（コマンドプロンプト）を確認
  1. 黒い画面をクリックして選択する
  2. キーボードの Ctrl を押しながら C を押す（強制停止）
  3. 黒い画面が閉じたら、予約システム起動.bat をもう一度ダブルクリック
  4. タブレットでリロードして確認
✔ 直った　→　そのまま使ってください   ✘ まだ直らない　→　下の連絡先に連絡してください
📞

ここまで試しても直らないときは、無理に操作せずオーナーに連絡してください。
予約の受付は引き続き紙の予約台帳で対応してください。
